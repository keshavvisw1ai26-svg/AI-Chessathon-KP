Chessathon Agent

How this agent was trained. The engine is a compiled alpha-beta search written in Python and JIT-compiled with numba, reaching about a million positions per second on one CPU core. Its evaluation is a small neural network, a 768 to 512 NNUE with two perspectives and eight output buckets, trained on over 150 million chess positions from the public Lichess evaluation database, each labeled by deep Stockfish analysis. The network is quantized to integers and updated incrementally as the search makes and unmakes moves, so a full evaluation costs about a microsecond. The agent also tracks repetitions, manages its clock, and thinks on the opponent's time.
